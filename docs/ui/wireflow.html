发现的问题

画这张图时从截图和源码里看到的不一致或可以改进的地方，按对用户的影响大致排序。

  1. 章标题几乎永远看不到。PassageView 用 scrollTo(目标节, anchor: .top)，没有高亮时目标是第 1 节，于是「书名 第 N 章」这一行总被滚出可视区（S2-S5、R2、R3 都看不到）；只有整章一屏放得下、滚不动时才露出来（R1）。
  2. 高亮节紧贴上方分隔线。同一个原因：第一条高亮节顶到分隔线，没有留白，上一节的语境也看不到（S2、S3、S4）。可以改为滚到目标节的前一节，或给锚点留出顶部间距。
  3. 阅读窗口里同一个引用出现三处且互不一致。R1 的标题栏是「哥林多前书 13:4-8」，工具栏中间是「哥林多前书 13」，正文上方还有「哥林多前书 第 13 章」。工具栏标题和章标题信息重复，节号只出现在标题栏。
  4. 选中色是红色。结果行用 Color.accentColor，高亮用它的 18% 透明度。这台 Mac 的系统强调色是红色，所以截图里选中是红色，看上去像报错；换一台机器会是别的颜色，截图不可复现。可考虑给 app 固定一个强调色。
  5. ⌘⏎ 复制之后没有任何反馈。copySelected() 写完剪贴板就直接隐藏窗口，没有「已复制」提示；S6 无匹配时按 ⏎ / ⌘⏎ 也毫无反应。
  6. 底部提示栏不完整。只列了 ↑↓ ⏎ ⇧⏎ ⌘⏎ esc；⌘D、⌘W、⌃N ⌃P 和「点击已选中的行 = 打开」都没有提示。
  7. ⌘Q 和 Dock「退出」不退出。这是有意设计，菜单里也改名为「关闭所有窗口（保留后台）」，但 Dock 右键菜单的「退出」是系统文案，点了之后图标仍带运行圆点，容易被当成卡死；真正的「退出好查经」没有快捷键。
  8. 点击 Dock 图标的行为不稳定。只有在没有可见窗口时才带回搜索；如果还开着一个阅读窗口，点 Dock 图标只激活 app，搜索窗口不出现。
  9. Space+P 在 app 自己处于前台时无效。从阅读窗口回到搜索只能用 ⌥Space 或 ⌘F，也不能用 Space+P 收起搜索；但菜单项「打开搜索  (⌥Space / Space+P)」和关于窗口底部的说明（「⌥Space 或按住 Space 再按 P 呼出搜索」）都把两者并列，Space+P 未授权或已停用时这些文字也不变。
  10. Space+P 菜单标题的刷新（已修复）。两个菜单现在每次打开都会通过 menuNeedsUpdate 重新读取状态，启动后才授予或撤销权限，标题也是对的；2 秒轮询除了启动时，也会由点击「开启 Space+P 快捷键（需授权辅助功能）…」重新开始。
  11. ⏎ 会覆盖最前面的阅读窗口。原来的经文被直接替换且无法后退；想保留必须记得用 ⇧⏎ / ⌘D。阅读窗口里也没有回到高亮节的办法，翻章后高亮永久丢失。
  12. 搜索窗口没被隐藏时输入不会清空。show() 只在窗口不可见时清空输入；如果搜索窗口只是被阅读窗口盖住，再按 ⌥Space 会带着上一次的输入回来，与从隐藏状态唤出的表现不同。

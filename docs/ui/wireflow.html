D1关于好查经（窗口）实拍
关于好查经
非模态的独立窗口（440×500），里面没有按钮，用红色关闭按钮或 ⌘W 关闭；已打开时再选「关于好查经」只是把它带到最前。「github.com/Lamonkey」是链接，点击后在浏览器打开 https://github.com/Lamonkey。
鼠标、选择与 esc
  • 点击某一行 = 选中它；再点已选中的行 = ⏎ 打开。
  • ↑ ↓ 与 ⌃P ⌃N 等价，由窗口级按键监听处理，输入框仍保持焦点。
  • 每次改动输入，选中项都回到第一条。
  • 带修饰键的 ⌘← ⌥→ ⇧← 仍是编辑输入；输入法正在选字时，esc、方向键、⏎ 都交给输入法。
  • 底部提示栏写了 ↑ ↓ ← → ⏎ ⇧⏎ ⌘⏎ esc，没有提 ⌘D、⌘W、⌃N ⌃P 和鼠标选节。
  • esc 一步一步退：有字时只清空（回到 S1），空的时候才收起；底栏按钮跟着写「清空」或「隐藏」。⌥Space、⌘W、⌘⏎ 收起时输入留着，只有 ⏎ / ⇧⏎ 打开经文会清空。
匹配规则（README）
  • 书名只做精确规则匹配：拼音首字母、拼音前缀、中文简称或全名；* 任意个音节，? 一个音节。
  • 候选书卷没有该章或该节会被排除，所以 yh 4:24 只剩约翰福音。
  • 章节分隔可用空格、冒号、全角冒号、点、逗号。
预览里选经节、← → 翻章
  • 鼠标在右侧预览里点一节、拖过几节、⇧ 点击延长：高亮和输入（如「约翰福音 1:1-2」）一起变，预览不滚动。
  • ← 上一章：落在最后一节，显示在预览底部，方便接着上文往回读；→ 下一章：落在第 1 节，章标题在顶部。
  • 输入被改写成中文全名（如「约翰福音 1:51」）；到书的首章 / 末章停住，底栏按钮变灰。
阅读窗口规则（ReaderWindow.swift）
  • 窗口标题 = 经文引用：带节号时「哥林多前书 13:4-8」，翻章后变「哥林多前书 14」。
  • ⏎ 总是用「最前面的可见阅读窗口」显示新经文，原内容被替换；想保留就用 ⇧⏎ / ⌘D。
  • 第一个阅读窗口居中出现，并沿用上一次关闭的阅读窗口的大小；之后的窗口从最前面的窗口错开。
  • ← → 是工具栏按钮的快捷键，不带修饰键：→ 从章首读起，← 停在上一章的章末（接着上文往回读），都不带高亮。「窗口」菜单由系统列出全部打开的窗口。
  • ⌘W 只关当前阅读窗口；关到一个不剩，app 也不退出（→ B2）。

发现的问题

画这张图时从截图和源码里看到的不一致或可以改进的地方，按对用户的影响大致排序。

  1. （范围已缩小）目标是第 2 节以后时看不到章标题。现在目标是第 1 节或整章时，PassageView 滚到的是章标题，「书名 第 N 章」留在最上面（S5、R2、R3 的截图里都看得到）。目标是第 2 节以后时仍是 scrollTo(目标节, anchor: .top)，章标题被滚出可视区（S3、S4）；R1 整章一屏放得下、滚不动，所以标题也在。
  2. 高亮节紧贴上方分隔线。同一个原因：目标是第 2 节以后时，第一条高亮节顶到分隔线，没有留白，上一节的语境也看不到（S3、S4）。可以改为滚到目标节的前一节，或给锚点留出顶部间距。按 ← 翻到上一章时是镜像的情况：最后一节紧贴预览的下边线（search-prev-chapter）。
  3. 阅读窗口里同一个引用出现三处且互不一致。R1 的标题栏是「哥林多前书 13:4-8」，工具栏中间是「哥林多前书 13」，正文上方还有「哥林多前书 第 13 章」。工具栏标题和章标题信息重复，节号只出现在标题栏。
  4. 选中色是红色。结果行用 Color.accentColor，高亮用它的 18% 透明度。这台 Mac 的系统强调色是红色，所以截图里选中是红色，看上去像报错；换一台机器会是别的颜色，截图不可复现。可考虑给 app 固定一个强调色。
  5. ⌘⏎ 复制之后没有任何反馈。copySelected() 写完剪贴板就直接隐藏窗口，没有「已复制」提示；S6 无匹配时按 ⏎ / ⌘⏎ 也毫无反应。
  6. 底部提示栏不完整。列了 ↑、↓ 选择、← 上一章、→ 下一章、⏎、⇧⏎、⌘⏎、esc；⌘D、⌘W、⌃N ⌃P、「点击已选中的行 = 打开」和「预览里可以用鼠标选经节」都没有提示。
  7. ⌘Q 和 Dock「退出」不退出。这是有意设计，菜单里也改名为「关闭所有窗口（保留后台）」，但 Dock 右键菜单的「退出」是系统文案，点了之后图标仍带运行圆点，容易被当成卡死；真正的「退出好查经」没有快捷键。
  8. 点击 Dock 图标的行为不稳定。只有在没有可见窗口时才带回搜索；如果还开着一个阅读窗口，点 Dock 图标只激活 app，搜索窗口不出现。
  9. （已不适用）第二个全局快捷键在 app 自己处于前台时无效。这一条说的是 Space+P 组合键；它连同权限提示和开关菜单项已整体移除，现在菜单和关于窗口里只写 ⌥Space。
  10. （已不适用）开关菜单项标题的刷新。那个菜单项已不存在，两个菜单的标题现在都是固定文字。
  11. ⏎ 会覆盖最前面的阅读窗口。原来的经文被直接替换且无法后退；想保留必须记得用 ⇧⏎ / ⌘D。阅读窗口里也没有回到高亮节的办法，翻章后高亮永久丢失。
  12. （已改）输入什么时候清空。show() 现在从不清空输入：清空只发生在 esc（escape()，有字时只清空、空的时候才收起）和 ⏎ / ⇧⏎ / ⌘D 打开经文之后（openSelected 里的 hide(clearQuery: true)）。⌥Space、⌘W、关闭按钮、⌘Q 和 ⌘⏎ 复制（copySelected 调的是不带参数的 hide()）收起时，输入、选中项和预览位置都留着，下次唤出原样回来并全选，方便复制完一处再回来复制下一处；「被盖住」和「被收起」两种情况现在表现一致。留下的输入没有期限，隔很久再唤出看到的仍是上一次的结果，这时按 esc 第一下只清空、窗口不走；代价不大，因为文字是全选的，直接打字就替换。
  13. 单按 ← → 不再移动输入框里的光标。只要有选中的结果，不带修饰键的 ← → 就是翻章，整个输入被改写成「书名 章:节」。想退回去改一个字母、或者 ⌥Space 回来后想按 → 取消全选接着改的人，会看到自己打的字被换掉；要移动光标得用 ⌘← / ⌘→、⌥← / ⌥→ 或鼠标。S6 无匹配时 ← → 又照常移动光标，同一个键两种意思。这条规则只写在 README 里。
  14. 选经节或翻章之后，缩写被换成中文全名。打的是 yhfy 1:1，鼠标选两节之后输入框里是「约翰福音 1:1-2」。这是有意的（yh 这类缩写对应几卷书，不写全名翻章时可能换书），代价是接下来想手改章节时面对的不再是自己打的缩写；如果当时选中的是 S4 那样的第二条结果，改写之后列表也只剩这一卷。影响不大。
